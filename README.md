# Breast Cancer Classification Using Support Vector Machine (SVM)

## 1. Abstract

Breast cancer is one of the major health challenges worldwide. Early and accurate classification of breast tumours can support medical decision-making. This project uses the Wisconsin Diagnostic Breast Cancer dataset to develop a machine learning model that classifies tumours as benign or malignant. The analysis is conducted using R, with data preprocessing, exploratory data analysis, and Support Vector Machine (SVM) classification. Model performance will be evaluated using suitable classification metrics.

## 2. Introduction

The objective of this project is to investigate how machine learning can be used to classify breast cancer tumours based on numerical features extracted from digitized images of fine needle aspirates.

## 3. Dataset

The Wisconsin Diagnostic Breast Cancer dataset is obtained from the UCI Machine Learning Repository.

- Total observations: 569
- Total variables: 32 (including ID and diagnosis)
- Benign cases: 357
- Malignant cases: 212
- Target variable: Diagnosis (Benign or Malignant)

## 4. Methodology

The project follows these steps:

1. Dataset collection and import using R.
2. Data cleaning and preprocessing.
3. Exploratory data analysis and visualisation.
4. Support Vector Machine (SVM) model development.
5. Model evaluation using classification metrics.
